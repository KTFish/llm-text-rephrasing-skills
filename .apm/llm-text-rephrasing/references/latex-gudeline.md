# Anti-llmish guidelines for Latex

1. Never change any content of the latex file like data, citations, links, file paths.
2. **Heading capitalization and numbering:** Format all titles and section headers in strict sentence case. Only the very first letter of the heading should be capitalized, with all subsequent words in lowercase (e.g., use "The title of the section" instead of "The Title of The Section"). Acronyms must not be used in headings. Only keep numbering for sections and subsections (subsubsections must be unnumbered, using `\subsubsection*{...}` in LaTeX or unnumbered headings in Markdown).
